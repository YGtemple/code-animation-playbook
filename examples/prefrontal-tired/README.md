# 实例六《前额叶没坏，是累了》——水彩手绘

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 引擎与喜剧结构不变，换成暖纸水彩皮肤，承载情绪跨度。

## 剧情

圆头小人班味过载、层层升级到崩溃，被一杯热茶温柔接住：

| 时间 | beat | 文案 |
|---|---|---|
| 0–3s | 冷开场 | "我的前额叶…" |
| 3–8s | 未读红点 1→99+ 晕开 | "早上 99+ 未读" |
| 8–13s | 领口班味水痕下晕，日历 1→12 | "班味，腌入味了" |
| 13–19s | 仪表盘指针打红区 100%，赭石晕染+汗珠 | "CPU超频——散热还是原装的" |
| 19–23s | 僵住、墨滴持续晕开、画面虚化；音频近停只留水滴 | （空） |
| 23–28s | 放下热茶，赭/红退成灰松石青，抬头 | **"前额叶没坏，是累了。"**（朱砂加粗） |
| 28–30s | 五瓣小野花、茶杯蒸汽、手写署名 | — |

## 皮肤要点

- 纸底 `#F5EFE0`，暖墨（非纯黑）`#3A3230`，焦虑赭 `#C97B5C`，崩溃朱砂 `#B84A3F`，
  降温松石青 `#7A9E9F`。
- 轮廓刻意不闭合、圆头；晕染 feGaussianBlur、径向渐变软投影（无硬投影）、纸纹 feTurbulence；
  **弱沸腾只抖描边、人脸与色块锁死**。
- 音乐 BPM72：尼龙吉他分解 + 钢琴单音（中段 b9）+ 暖 pad(lowpass800) + 水滴混响 + 茶杯"叮"。
- **字体随示例自带（`fonts/`，均 OFL）**：Caveat（数字标注，可变）、Patrick Hand（小标签）。
  中文毛笔用 ZhiMangXing（全仓库共享，见下）。

## metrics 重定义（旧黑+红作废）

- 第三条改测【墨线+主晕染覆盖比】，HSV 色盒：墨线 / 焦虑晕染 / 崩溃红；
  排除纸底与降温青；覆盖率 = 掩码 /（总像素 − 纸底），阈值 ≥8%。
- 帧差 ≥6；静止帧放宽到 ≤12%，峰值段不得有超过约 0.6s 完全像素静止（靠晕染/蒸汽打破）。

## 运行

> 中文毛笔字体为全仓库共享、未在示例重复存放，先从根 `fonts/` 复制 ZhiMangXing：

```bash
mkdir -p fonts && cp ../../fonts/ZhiMangXing.ttf fonts/
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm install
CHROMIUM_PATH=/usr/local/bin/chromium npm run render
npm run sfx && npm run metrics
TITLE="前额叶没坏是累了" npm run encode
```

无生成式模型、无外部素材。
