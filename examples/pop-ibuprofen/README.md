# 实例十七《电子布洛芬 · 止痛不治本》——复古波普漫画风（Lichtenstein / 美式漫画，带 TTS 中文旁白）

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 引擎与喜剧结构不变，换成三原色 + Ben-Day 网点 + 粗黑描边 + 分格/气泡/爆裂框的硬朗美式漫画；含 TTS 中文人声旁白。

## 剧情

漫画「止痛侠」胸口写着「难受」，追着一只蓝点黑影「空虚怪」。他靠不断吞下升级剂量的「电子布洛芬」揍退怪物，每吞一颗炸一个爆裂框；可怪物每次都换更大的尺寸回来——

| 段落 | 画面（波普） | 爆裂字 / 关键数字 |
|---|---|---|
| 封面 splash | 整页黄星炸 + 英雄剪影 | 《电子布洛芬》第1话 VOL.17 |
| 处境 | 侠捂胸口，蓝网点空虚怪探出，思想泡「好难受」 | — |
| R1 | 红胶囊掉下吞下，红网点场 | POW · 搞笑短视频 15s · 剂量×1 |
| R2 | 黄丸大一号，黄网点 | WHAM · 治愈 vlog 30min · ×2 |
| R3 | 蓝巨丸比侠大，螺旋眼，怪长 2 倍，低电量 | BAM · 通宵刷不停 · ×3 |
| R4 | 整座手机当药丸砸出，怪炸网点重拼更大 | KAPOW · ×99+ · 「更空虚」 |
| 反转 | 配乐急停，医生推处方；侠慢慢放下手机，怪缩成蓝网点 | 处方「药效40秒，副作用：更空虚」 |
| 落版 | 侠走进纸白，旁白框点题 | 「屏幕给的是止痛药，你给自己的才是治疗。」彩蛋 SCREEN TIME 03:47 |

「电子布洛芬」给的是短暂镇痛、不解决现实；真正的处方，是把屏幕放下。
彩蛋：红点通知、加载转圈、低电量、竖屏进度条、红心点赞、闹钟、今日屏幕使用时间。

## 皮肤要点

- 色板（锁死 5 色）：纸白新闻米 `#F4EDD8`、漫画黑 `#111111`、原色红 `#E2231A`、原色黄 `#F4C20D`、原色蓝 `#1E5AA8`；
  不出现绿/橙/紫/棕（「紫」靠红蓝网点视觉混色）；网点不引入新色相。
- **Ben-Day 网点（SVG `<pattern>`，明暗全靠网点密度、绝不用实心灰）**：中间调间距 26/r4.2(≈8%)、深阴影间距 15/r5.2(≈37%)、
  最重间距 11/r5.4(≈70%，仍透纸白、不是实心黑)；脸 = 纸白 + 红浅网点(间距30/r3≈3%)，颈下/阴影叠蓝网点；
  网点层用 clipPath 限定在形状内；剂量加大靠网点密度档位跳变。
- 造型：统一黑描边、主轮廓 stroke-width 12–14px、气泡 6–8px、爆裂框 10px；硬边、无柔边、无写实投影
  （落地影 = 一团蓝密网点硬切）；panel 边框 8–10px、gutter 留 16–20px 纸白；12–16 角星 burst 可破格出血。
- boil：**关**。生命感靠切格(panel cut)、爆裂框 scale 弹簧 punch(1→1.35→1，3帧)、气泡弹出(scale0→1，2帧)、网点档位跳变。
- 音乐：1960s surf rock 冲浪摇滚 **150 BPM**（1拍=12帧，切格/爆裂卡拍）；twang 电吉他(弹簧混响感 G–C–D)+走步贝斯+军鼓 rimshot，
  每记 POW 砸铜管 stab。音效：POW=60Hz 下滑重击+白噪爆点+卡通 boing；气泡 blip；切格翻页噪声；手机震动；20s 配乐急停。

## 旁白文案与音色（TTS，唯一生成式环节）

音色：**30 岁上下、明快略带夸张的解说腔**（动画/体育解说感、上扬有戏但不油腻），冷静报药量 vs 画面荒诞。逐句生成、按点对位：

| 句 | 时间 | 文案 |
|---|---|---|
| 1 | 3.0s | 他很难受。难受，就得吃药。 |
| 2 | 6.5s | 第一颗，搞笑短视频。爽，三秒。 |
| 3 | 10.5s | 剂量加倍。这药，不能停。 |
| 4 | 14.5s | 最后他把整座屏幕，吞了下去。 |
| 5 | 20.5s | 医生说：这不是药，是镇痛剂。 |
| 6 | 26.5s | 真正的处方，他今天才看懂。 |

> 第 1 句首版演绎过慢，已用「语速偏快、紧凑」重新生成；26.5s 句后留白 ~2.5s，反转不解释。

## metrics 重定义（波普口径，旧黑红/逐帧指标作废）

下采样 160×90，按最近色归 5 桶 + other(≤2%)。五指标：

1. `dot_cov` 网点覆盖：对红/黄/蓝桶分别 3×3 开运算，网点 = 原色桶 − 开运算大块，网点/全帧。
2. `ink_ratio` 粗黑描边：黑桶/全帧，目标 4–7%。
3. `primary_box` 三原色：(红+黄+蓝)/全帧 35–55%，且各色 ≥8%。
4. `panel_motion`：裁掉边距/gutter，内容区爆裂框/人物连通块同位置 3 帧内面积 ±30% 跳变；全片有效事件 ≥8 次。
5. `dead`：内容区帧差<1.5 且 panel 边框不变 且爆裂框面积不变，连续 ≥40 帧(1.3s) 才报警；死帧占比 ≤12%。

- 实测：ink 6.36%、primary 36.14%(R9.9/Y7.9/B18.3)、运动事件 105、死帧 7.01%，均达标。
- **口径教训（见 docs/pitfalls P16）**：`dot_cov` 在 160×90 NEAREST 下，26px Ben-Day 网点与 12px 采样网格亚像素错拍、被混为纸白，
  读数仅 ~3%，但 1080p 画面网点真实丰富（全帧实测单帧网点 2–4%、密阴影区更高）。该指标阈值需按「全分辨率/网点占所在阴影区比例」重基线，勿为凑数把网点加大到画面发脏。

## 运行（Windows / PowerShell；其他系统同理）

> Anton（POW 爆裂字，OFL）与站酷快乐体 ZCOOL KuaiLe（中文气泡，OFL）已随示例（`fonts/`）。
> 大字体站酷庆科黄油体（中文大标题，8.3MB）未入库，需自行获取到 `fonts/`（亦在仓库根 `fonts/`）：

```powershell
Copy-Item -Recurse -Force ..\..\node_modules .
New-Item -ItemType Directory -Force fonts | Out-Null
Copy-Item ..\..\fonts\ZCOOLQingKeHuangYou.ttf fonts\   # 或从 jsDelivr 获取

# 1) 逐帧画面（render_frames.js 已配本机 Chrome；其他系统改 executablePath）
node render_frames.js
# 2) 纯代码配乐/音效床（产出 bed.wav）
python sfx.py
# 3) TTS 旁白：用 text_to_audio_plus 逐句生成，裁剪首尾静音，按 voice_manifest.json 存 voice/c_v1.wav … c_v6.wav
# 4) 旁白对位 + ducking 混音（产出 mix_voice.wav / mix_novoice.wav）
python mix_voice.py
# 5) 编码两版 MP4
powershell -File encode.ps1
```

无生成式模型（TTS 旁白为明确例外）、无外部素材。
