# 实例十二《AI 不能欠薪》——等距 3D isometric 风（带 TTS 中文旁白）

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 引擎与喜剧结构不变，换成深夜仪表盘上的等距积木小世界；含 TTS 中文人声旁白。

## 剧情

公司把人优化掉换上 AI，效率拉满、账单也拉满；欠费当天 AI 当场停工，老板连夜把"招聘中"牌子挂回去——因为人的工资，可以拖：

| 段落 | 画面（等距几何） | 关键数字 |
|---|---|---|
| 钩子 | 橙色人类块工位上工牌当啷落地，青色 AI 块滑入占住岛中央，红章"优化"盖下 | 优化 |
| R1 | 人类块被推下岛消失，青块滑到正中顶亮◉，咖啡杯留在原位 | AI 到岗 |
| R2 | 青块竖向堆成 3 层效率塔，Token 转盘猛转、数字飞跳 | 效率 +400% |
| R3 | 红色账单块从天上摞到岛上方越摞越高，转盘点成 ¥ 飙升 | 算力账单 ¥4886 |
| R4 | 青块骤然变灰、效率塔哗啦散架，转盘停"欠费"，岛灯暗一半 | 欠费 |
| 反转 | 光标移入"叮"地立起白底招聘牌，橙色人类块探回、端起咖啡，金章"招聘中"盖下 | 招聘中 |
| 定格 | 招聘牌 + 橙人块 + 咖啡同框 | — |

把宇宙一贯的"AI 碾压人"母题**倒置**：人类唯一的优势是便宜、好拿捏、工资可以拖。
彩蛋：工牌（被收走又挂回）、Token 计数器、印章（优化→招聘中）、咖啡（人走了还在桌上）、光标（点招聘链接）。

## 皮肤要点

- 深夜仪表盘底 `#1B1E26`；人类暖橙 `#E8833A`、AI 电子青 `#39C5D6`、账单警报红 `#E4574D`、
  中性纸白 `#F2F0EA`、印章金 `#D9A441`；地板网格线 `rgba(242,240,234,0.07)`。
- 等距块同色三面假三维（**禁渐变**）：顶面亮 12%、侧面暗 18%、正立面取本色。
- 唯一基本型＝等距长立方体；人物＝圆角小方块 + 两点眼；硬边、倒角 ≤2px。
- 每块体在地板投固定方向（30°）软暗影 `rgba(0,0,0,0.25)` 模糊 2px、随真实位移而动。
- **boil 关**：活感全部来自真实几何运动（块体缓动/堆叠、Token 转盘恒转、账单逐个落下、印章落下+回弹）；
  每回合至少 2 类同时运动。半透明仅用于地板网格线与投影，且剔除出帧差统计。
- 音乐 lo-fi 电子 chill，BPM96–100：软合成贝斯 + 弱琶音 + 轻电子碎拍；
  块堆叠=木质"哒"、账单落=低"咚"、盖章=砰+纸摩、AI 停工=电流"滋"后静音、招聘牌挂回=轻"叮"。

## 旁白文案与音色（TTS，唯一生成式环节）

音色：**冷静、清晰、略带调侃的中文男声**。逐句生成、按时间点对位：

| 句 | 时间 | 文案 |
|---|---|---|
| N1 | 1.0s | 公司把人裁了，换上了 AI。 |
| N2 | 9.0s | 确实快，连轴转，不喊累。 |
| N3 | 16.0s | 只是它的账单，也是真的。 |
| N4 | 22.0s | 欠费当天，它当场就停工了。 |
| N5 | 26.0s | 老板连夜挂回招聘链接——毕竟，人的工资，可以拖。 |

> N5 为金句、音乐收半拍只留"叮"，把笑点让给人声；旁白不提前剧透。

## metrics 重定义（等距口径，旧指标作废）

- 帧差只算活动包围盒（工位岛+块体+计数器），不含全局死底与极淡网格线；地板暗影与网格线剔除。
- 活帧三判据（任一）：活动包围盒变化、实心块色值分布变化、计数器数字（含恒转转盘 ROI）变化；
  三者同时静止且持续 >0.4s 判死帧；真死帧连续 ≤0.4s（约12帧）。
- 每回合强制 ≥2 类同时运动；色盒只对实心活性块取色（半透明投影/网格不计）。
- 实测：平均活动区帧差 14.93、最长连续死帧 1 帧（0.03s）、死帧占比 0.12%（活帧 99.89%）；900 帧断言 PASS。

## 运行（Windows / PowerShell；其他系统同理）

> Space Grotesk 已随示例（`fonts/`，OFL）；中文 Noto Sans SC 体积大、需下载到 `fonts/`。

```powershell
Copy-Item -Recurse -Force ..\..\node_modules .
New-Item -ItemType Directory -Force fonts | Out-Null
curl.exe -L -o fonts/NotoSansSC.ttf "https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf"

# 1) 逐帧画面（render_frames.js 已配本机 Chrome 路径；其他系统改 executablePath）
node render_frames.js
# 2) 纯代码配乐/音效床（产出 sfx_music.wav）
python sfx.py
# 3) TTS 旁白：用 text_to_audio_plus 逐句生成，存为 voices/N1.wav … N5.wav
# 4) 旁白对位 + ducking 混音（产出 narrated.wav / instrumental.wav）
python mix.py
# 5) 编码两版 MP4
powershell -File encode.ps1
```

无生成式模型（TTS 旁白为明确例外）、无外部素材。
