> 引擎与喜剧结构不变，换成大量留白的极简扁平皮肤。

## 皮肤要点

- 近白底 `#FAFAF7`，发丝线 `#E7E5DE`，墨 `#191919`，唯一强调色 信号橙 `#FF5A2D`，
  系统蓝 `#2F6BFF`；圆角即立场（人侧 8px 软 / 系统侧 2px 硬）。
- 零投影 / 零噪点 / 零渐变；**boil 关闭**，帧差只来自真实 UI 运动（光标 530ms 闪烁、
  typing 三点、逐帧时钟/大百分比计数、顶部橙色扫掠块、环/条填充、卡片转场、印章 clip 展开）。
- 音乐极简电子 + lo-fi，BPM96：滤波方波 pluck + 轻 808 + 稀疏 hihat + 圆角钢琴；
  反转前全曲留白 0.5s 再单低音"咚"。
- **拉丁字体随示例自带（`fonts/`，OFL）**：Inter（UI，可变）、JetBrains Mono（数字/代码，可变）。
  中文用 Noto Sans SC（思源黑体，见下，体积大故不随示例）。

## metrics 重定义（留白扁平口径）

- 活性覆盖＝墨线（V<0.18）＋信号橙（H[6,11],S>0.65,V>0.5），蓝不计；普通帧目标 2.2–7.5%、
  大字屏 1.2–12%（排除入场淡入/反转白窗）。
- **帧差用【内容区口径】**：背景（V>0.93,S<0.08）不参与，内容掩码取相邻帧任一非背景并膨胀；
  有真实运动的帧内容区 |ΔV| ≥3（整帧 ≥6 是 boil 全屏抖动时代的阈值，扁平不适用）；
  真死帧（内容区<0.1）连续 ≤0.4s。
- 实测：有运动帧 5.94、真死帧最长 0.10s、活性 2.46–5.68%、900 帧。

## 运行

> 中文字体体积大、未随示例，先下载 Noto Sans SC（OFL）到 `fonts/`：

```bash
mkdir -p fonts
curl -L -o fonts/NotoSansSC.ttf \
  "https://github.com/google/fonts/raw/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf"
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm install
CHROMIUM_PATH=/usr/local/bin/chromium node render_frames.js
python3 sfx.py && python3 metrics.py
```

无生成式模型、无外部素材。
