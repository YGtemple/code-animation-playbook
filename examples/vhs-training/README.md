# 实例十六《员工培训录像带 1995：如何体面地熬完这一天》——复古 VHS 录像带风（带 TTS 中文旁白）

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 引擎与喜剧结构不变，换成模拟老化、过录失真、暖褪色的 VHS 皮肤；与实例五干净数字霓虹赛博区分。

## 皮肤要点

- 色板：磁带暖黑 `#0d0b12`、褪色暖白 `#e8dcc8`、褪草绿 `#7a8b5a`、褪雾霾蓝 `#5a7a9a`、怀旧暖黄 `#d9a441`；
  故障青 `#00e5ff`、故障品红 `#ff2bd6`（只在高对比边缘水平溢色与故障瞬间、绝不铺大面积）；
  OSD 青字 `#9dffc4`、REC 红点 `#ff2a2a`(1Hz 闪)、tracking 灰 `#3a3a42`。
- 后处理（post_vhs.py，对干净 PNG 批量施加）：
  ① chroma bleed（最重要）：转 YUV，只糊 U/V 水平 σ3–4px、Y 不糊，强度 40–60%；
  ② R/B 水平错位 ±1.5–2px；③ Y 轻糊 σ1.2；④ scanline 隔行压暗 25–40%；
  ⑤ 饱和度降到 60–65% + 暖漂（R−B +8~12，注意暖漂放在降饱和之后才测得到）；
  ⑥ 全帧加性高斯磁噪 σ8–12；⑦ 底部 tracking 带 48–72px 缓慢垂直滚动、故障加宽 120px；
  ⑧ dropout 每 2–4s 一条亮水平短划；⑨ jitter ±0–2px、每 5–8s 单帧撕裂 4–10px；⑩ 暗角 8–12%。
- 重 glitch 只在暂停/掉磁/倒带瞬间爆发；平时软、暖、克制（全程拉满噪波=滤镜感，不可信）。
- 音乐 chillwave/lo-fi synthwave BPM94（Dm–B♭–F–C），暖电钢铺底、轻 hat、wow&flutter ±0.3%；
  音效 tape hiss(−40dB)、OSD 嘀(1kHz)、倒带下行扫频、dropout 呲爆音。

## metrics 重定义（VHS 口径；颜色类改受控老化量）

- 受控老化量（设计值、报告在区间即可）：bleed_px（高对比边缘 UV 比 Y 宽，3–4px）、
  drift_warm（全帧 R−B +8~12，实测 +7.5）、saturation_lvl（0.60–0.65，实测 0.62）。
- 磁噪 vs 主体分离（核心）：D=|Y_t−Y_{t−1}| 拆三层——
  ① 底部 ROI(y≥1008) tracking 滚动单列 tracking_motion、剔出主体；
  ② 3×3 高通取全帧 grain_sigma（健康 8–12、上限 15）；
  ③ 剔除 tracking ROI 后 D>3grain + 3×3 中值 + 连通域，只保留 >0.3% 画面(≈1800px) blob 记 subject_motion。
- 死帧：连续 45 帧(1.5s) 主体 blob<0.1% 且无章节切才报警；grain/tracking 全程存在但绝不并进运动分。
  办公室静坐镜头（grain/tracking/REC 闪全程在）属"健康静场"，非渲染死帧。

## 编码与体积（重要）

VHS 颗粒/磁噪是高频随机噪声，低 CRF 会让码率爆炸（CRF18 曾达 111Mbps、单文件 398MB）。
**颗粒类风格用高 CRF（24–26）编码**：噪声掩盖压缩损失、视觉基本无损，成片压到约 57MB（视频码率 ~16Mbps）。

## 运行（Windows / PowerShell；其他系统同理）

> 小字体已随示例（fonts/ShareTechMono.ttf、fonts/ArkPixel12-zh_hans.woff2）。

```powershell
Copy-Item -Recurse -Force ..\..\node_modules .

node render_frames.js   # 1) 干净主体逐帧（改本机 Chrome executablePath）
python post_vhs.py      # 2) 施加 chroma bleed/磁噪/tracking/scanline/暖漂（frames_post）
python sfx.py           # 3) chillwave 配乐 + hiss/倒带/OSD 音效床（bed.wav）
# 4) TTS：text_to_audio_plus 逐句生成、裁静音存 voice/v1..v8.wav（V8 atempo 1.30）
python mix_voice.py     # 5) 旁白对位 + ducking（mix_voice.wav / mix_novoice.wav）
powershell -File encode.ps1   # 6) 编码两版 MP4（用 CRF 24–26 + faststart）
```

无生成式模型（TTS 旁白为明确例外）、无外部素材。
