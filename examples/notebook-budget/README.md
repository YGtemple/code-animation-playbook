# 实例十八《这个月，我要纯过日子》——手绘笔记本涂鸦风（带 TTS 中文旁白）

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 引擎与喜剧结构不变，换成横线笔记本 + 圆珠笔速写 + 便利贴/涂改液的手账小世界；含 TTS 中文人声旁白。

## 剧情

一个人翻开新本子，踌躇满志写下「本月省钱计划」，四条规矩一条比一条狠、每做到一条打一个钩、画颗星星；全本打满红钩、页边一片得意涂鸦。最后翻到记账明细——

| 段落 | 画面（涂鸦） | 关键数字 |
|---|---|---|
| 开场 | 本子摊开，笔落下，标题逐字写出，黄便利贴「冲！」 | 便利贴角小字「Token 余额：不足」 |
| R1 | 「①戒奶茶·戒30块的咖啡」，咖啡杯打叉，红√ | 划掉 ¥30/天 |
| R2 | 「②自己带饭，不点外卖」，丑便当涂鸦，√，冒星星 | 省 ¥25/顿 |
| R3 | 「③走路通勤，不打车」，火柴人狂奔出汗，√，笑脸 | 省 ¥40/天 |
| R4 | 「④不买！能蹭就蹭！」，页边小怪兽举旗，红钩打满半页 | 蓝章「已省（并没有）」 |
| 翻页 | 得意翻到「本月记账明细」 | 三笔省下 30+25+40 |
| 明细 | 支出划掉又写回，手型光标戳购物车，总额被涂改液盖三层 | 9.9包邮×37 / 大米×20袋 / 洗衣液×8瓶 |
| 反转 | 箭头/红圈戳涂改液，掀开露「结余：¥0.00」，小怪兽破防挂泪 | **¥0.00**；彩蛋「您已下单第402件小垃圾」 |

钱是省下来了，东西也没少买——主动抠门，又忍不住下单。
彩蛋：Token 余额便利贴、手型光标、蓝印章、咖啡杯、第402件小垃圾。

## 皮肤要点

- 笔记本纸：**横线本**，暖米白底 `#f7f1e3`（非纯白）、四角极轻旧化；横线 `#c9d6e8` 粗1px、行距72px；
  左侧红色 margin 竖线 `#e08a8a` 距左110px、粗2px；页脚手绘页码「- 7 -」。横线/红竖线是固定背景层、全程不动（metrics 必须 mask）。
- 笔迹：主笔圆珠笔蓝黑 `#2b4a6f`，重点/打钩/反转红圆珠笔 `#c0392b`，铅笔灰 `#5a5a5a`（草稿/划掉旧字），
  便利贴黄 `#f5e6a3`；小怪兽/星星可少量绿 `#6a9955`。笔触宽 2.5–3.5px、带手抖(±0.8–1.5px)、起收笔略圆、重点线两次描。
- 涂鸦词汇：火柴人(出汗/跑/瘫/举拳)、手绘弯箭头、不规整星星、小花小草、不规则气泡、歪✓✗、黄便利贴(旋转±4°)、
  涂改液白块(毛边、盖1–3层)、页边圆乎乎举旗小怪兽、极简表情脸。
- 上屏字要「写出来」：逐字 opacity/书写入场(0.15–0.3s/字)，不整段淡入；基线故意 ±4px 歪斜。
- 投影/boil：基本无写实投影（只便利贴下方 2–3px 15% 灰错位边、翻页页角阴影）；**boil 全局关**（只局部笔迹 ±0.5px 微抖），
  靠逐元素入场/打钩/贴纸/翻页保活。
- 音乐：轻快 ukulele + 口哨 **112 BPM**（C–G–Am–F，口哨主旋律带 vibrato、沙锤/指板敲击）；
  音效：写字沙沙(白噪带通2–5kHz断续)、打钩唰、翻页哗啦、便利贴啪、涂改液咻啪、笔尖嗒；反转音乐停半拍、口哨跑调泄气尾音。

## 旁白文案与音色（TTS，唯一生成式环节）

音色：**轻松生活化、像朋友坐旁边一起吐槽的年轻女声**，自然不播音腔、不热情，像边看账单边念叨。逐句生成、按点对位：

| 句 | 时间 | 文案 |
|---|---|---|
| 1 | 2.8s | 每个月一号，我都特别有理想。 |
| 2 | 6.5s | 戒奶茶，带饭，走路上下班。 |
| 3 | 11.5s | 这几样，我一样没落下。 |
| 4 | 18.5s | 这个月，我觉得自己可会过了。 |
| 5 | 23.0s | 直到我翻开记账的那一页。 |
| 6 | 26.3s | 钱是省下来了，东西，也没少买。 |

> 末句原计划 28.3s 会顶破 30s（该句自然演绎约 3.3s），已把起点提前到 26.3s（第5句收25.78后留0.5s），末句 29.62s 收；
> 它正好压在「掀开涂改液露结余」的反转上，画面不提前说破。

## metrics 重定义（涂鸦口径，留白多 → 内容区口径，旧逐帧/颜色指标作废）

先 mask 背景：纸色(|RGB−#f7f1e3|<12)、横线、红竖线、便利贴底色一并 mask；content_mask = 只留笔迹/涂鸦/便利贴上字/小怪兽。五指标：

1. `ink_ratio` 非纸色笔迹 = content_mask/全帧，目标 0.6–3.5%（<0.5 太空、>6 太满）。
2. `ink_texture` 手写线条活性：content_mask 区拉普拉斯绝对值均值，应 > 干净矢量基线 1.5×。
3. `content_diff` 内容区帧差：paper_mask 区差分置 0，只算笔迹区 |Y_t−Y_{t−1}|，写字帧有局部波峰。
4. `sticker_motion`：连通域找黄底近矩形/倾斜色块，跟踪质心与旋转，贴纸一次性到位。
5. `dead`：连续 60 帧(2s) content_diff 无峰且 ink_ratio 无增长才报警（不能用全局帧差≈0 判死）。

- 实测：ink_ratio 均值 4.93%（前/中/尾 0.21→7.51→4.03，随书写上升、翻页后重建；记账页信息密故均值略高于3.5%上限）、
  ink_texture 68.1、content_diff 峰 41.9、死帧 0。
- **口径提示（见 docs/pitfalls P16）**：记账明细页笔迹密集，`ink_ratio` 会瞬时超 3.5%，属该镜头的表达性密度；阈值应按「分镜头基线」而非全片一刀切。

## 运行（Windows / PowerShell；其他系统同理）

> 站酷快乐体 ZCOOL KuaiLe（涂鸦大标题/便利贴，OFL）已随示例（`fonts/`）。
> 大字体霞鹜文楷 LXGW WenKai（正文手写，15.6MB）未入库，需自行获取到 `fonts/`（本机 fontpool 已有）：

```powershell
Copy-Item -Recurse -Force ..\..\node_modules .
New-Item -ItemType Directory -Force fonts | Out-Null
Copy-Item <fontpool>\LXGWWenKai.ttf fonts\   # 或从 jsDelivr 获取

# 1) 逐帧画面（render_frames.js 已配本机 Chrome；其他系统改 executablePath）
node render_frames.js
# 2) 纯代码配乐/音效床（产出 bed.wav）
python sfx.py
# 3) TTS 旁白：用 text_to_audio_plus 逐句生成，裁剪首尾静音，按 voice_manifest.json 存 voice/c_v1.wav … c_v6.wav
# 4) 旁白对位 + ducking 混音（产出 mix_voice.wav / mix_novoice.wav）
python mix_voice.py
# 5) 编码两版 MP4
powershell -File encode.ps1
```

无生成式模型（TTS 旁白为明确例外）、无外部素材。
