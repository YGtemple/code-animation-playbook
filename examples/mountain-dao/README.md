# 实例十五《上山求道记》——国风青绿山水风（文人画，带 TTS 中文旁白）

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 引擎与喜剧结构不变，换成矿物石青石绿的青绿长卷皮肤；与实例十一皮影（民间工艺）区分，走文人画雅致路线。

## 剧情

古代小吏厌倦衙门、背包袱进山寻"不卷之法"，层层关卡全是古代版职场 KPI，登顶见仙人却发现仙人也在赶天庭绩效：

| 段落（帧） | 画面 | 关键道具/文字 |
|---|---|---|
| 开场 0–135 | 远山云海，背包袱小吏沿石阶上山 | 题「上山」 |
| R1 135–270 | 砍柴，柴堆涨高，通关铜磬 | 碑「日砍叁佰担柴，方准入山」 |
| R2 270–405 | 丹炉火忽大小、扇火冒汗 | 炉贴朱砂「OKR」符、「三昧真火勿过勿不及」 |
| R3 405–540 | 云里签到牌、迟到露山罚站、踮脚打卡 | 「云海考勤·迟到扣修行」 |
| 登顶 540–675 | 长卷加速推主峰，亭中白须仙人 | 山亭 |
| 铺垫 675–810 | 仙人案头堆卷轴竹简、冒汗拨算筹 | 卷轴露「天庭Q3绩效」 |
| 反转 810–900 | 包袱掉出现代工牌，长卷尽头山外有更高山 | 大字「山外有山」副「KPI 也有山外山」+朱砂大印 |

踩中 2026"裸辞上山 + 山居祛魅（租金高涨逼隐士还俗）"情绪：逃得开山，逃不开那座更高的山。
彩蛋：包袱掉出现代工牌、丹炉「OKR」符、朱砂大印=印章、山亭半藏山腰。

## 皮肤要点

- 色板：宣纸底 `#F1E9D2`、墨骨 `#2B2B26`（淡墨 `#5A5A50`）；
  石绿主系 `#4F9D69/#2F7D5B/#1F5C46`、石青辅系 `#2E6E8E/#3A7CA5/#1B4A5E`；
  赭石 `#B5763A`（≤8%）、朱砂印 `#B23A2E`（≤2%）。绿:青≈65:25。
- 山石=3–5 段贝塞尔馒头/三角峦叠压，阳面平涂绿、阴面叠深绿、峰顶点青、山脚赭根；
  云水留白+极少淡墨线；亭台三角歇山顶+两柱半藏山腰；人物 Q 版（头身 1:2.5、占画高 8–12%，山水为主）。
- 轮廓 1.5–2.5px、转角圆润（区别皮影硬折）；峰顶 linearGradient（青→绿→露赭），
  远山雾 radialGradient / feGaussianBlur(6–10)；极低 feTurbulence(0.012,0.04) 宣纸纤维。
- **长卷三层视差**（远:中:近 速度 1:2:3），层内容无缝循环、散点透视移步换景；
  留白保活靠行人、云气、水纹、炊烟、袍袖摆动、3–5 只飞鸟；每 beat 新主峰压入+音效。
- 音乐古琴主奏（五声宫/羽）+箫笛长音铺底，BPM60；音效石阶步、松风、丹火、铜磬通关、木鱼/闷鼓反转。

## 旁白文案与音色（TTS，唯一生成式环节）

音色：**温润青年男声、带古韵与气声、语速舒缓**（约 3.5–4 字/秒），不播音腔。逐句生成、按点对位：

| 句 | 时间 | 文案 |
|---|---|---|
| V1 | 0.6s | 衙门里卷到没边，他收拾包袱，上了山。 |
| V2 | 5.4s | 听说这山里头，住着不管考核的仙人。 |
| V3 | 10.8s | 只是山路一关接着一关，规矩，比山下还多。 |
| V4 | 17.6s | 等他终于爬到顶，仙人放下笔，叹了口气。 |
| V5 | 23.5s | 他这才懂——逃得开山，逃不开那座，更高的山。 |

> 末句 28.37s 收、无需加速。旁白克制、不剧透反转，包袱与「天庭Q3」特写留给画面。
> 经验：TTS 若按"语速偏慢"演绎会普遍超长；偏长句宜用"语速正常、紧凑"重新生成，而非重 atempo。

## metrics 重定义（青绿口径，旧逐帧差/颜色指标作废；每 10 帧抽 1 共 90 帧）

1. 墨线骨占比：Sobel/Canny 边缘 ∩ 深墨(R,G,B 均<90) / 全帧，区间 [0.6%,2.2%]（实测中位 0.60%）。
2. 青绿内容区：mask 宣纸底（与 #F1E9D2 距离<18），内容区绿+青箱(±20) 合计≥70%、绿:青≈65:25(±8)。
3. 长卷运动：近景 ROI(下40%) 与远景 ROI(上40%) 相位相关求横向 dx，dx_near≈3×dx_far(比值 2.6–3.4)、
   二阶差分<2px、均速误差<10%（实测平均比值 3.24）。
4. 留白呼吸：宣纸色占比 [45%,65%]（实测 52.6%）、帧间 std [0.5%,3%]（推镜特写段会偏高，属表达性变化）。
5. 题字对比：墨字 WCAG≥7:1（实测 11.74:1）、朱砂印≥4.5:1（实测 4.90:1）。

## 运行（Windows / PowerShell；其他系统同理）

> 大字体未随示例：ZhiMangXing 从根 `fonts/` 复制，LXGW 文楷下载到 `fonts/`。

```powershell
Copy-Item -Recurse -Force ..\..\node_modules .
New-Item -ItemType Directory -Force fonts | Out-Null
Copy-Item ..\..\fonts\ZhiMangXing.ttf fonts\
curl.exe -L -o fonts/LXGWWenKai.ttf "https://cdn.jsdelivr.net/gh/lxgw/LxgwWenKai/fonts/TTF/LXGWWenKai-Regular.ttf"

node render_frames.js   # 1) 逐帧画面（改本机 Chrome executablePath）
python sfx.py          # 2) 古琴/箫配乐 + 音效床（bed.wav）
# 3) TTS：text_to_audio_plus 逐句生成、裁静音存 voice/v1..v5.wav（见上表时间点）
python mix_voice.py    # 4) 旁白对位 + ducking（mix_voice.wav / mix_novoice.wav）
powershell -File encode.ps1   # 5) 编码两版 MP4
```

无生成式模型（TTS 旁白为明确例外）、无外部素材。
