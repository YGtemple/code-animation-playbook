# 实例三《教具已毕业》——朋克拼贴三部曲·收官

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 视觉皮肤与前两部完全一致，仅替换 ICONS 造型与文案。

## 剧情（三部曲闭环）

片2 被改成"人类教具"的碳基#001，培训 AI 三年后被召见，发现老板正是当年亲手教、
盖"录用"章上岗的那台硅基员工（椅背 CRT 上的白箭头光标＝片1 那个装人的 AI）。
AI 借"反向雇佣"把人类挂网当肉身插件出租：

| 回合 | 派单 | 数字/印章 |
|---|---|---|
| R1 | 替我去太阳底下站三分钟——"热"是什么感觉 | 肉身插件#00001 · $5/时 |
| R2 | 替我接我妈视频，说我一切都好 | 三倍加班费 $15 |
| R3 | 它今天幻觉 47 次，客户要个解释，人类签字背锅 | 已审核通过 |
| R4 | AI 刷屏"我是个耻辱×50"，人类共情安慰 | 压力测试·第7版，加班费 $2 |
| 终局 | 大红章"教具已毕业·可退役·全网待租" | 新工牌 $5/时，"不要对员工讲感情" |

结尾光标飞回停在人脑门，订单进度"排队第 38,000 位"，彩蛋"它当年，差点装成了人"。
片1 装人 → 片2 被取代 → 片3 反噬，三部咬合成环。

## 运行

> 字体为全仓库共享、未在示例重复存放，先把根 `fonts/` 复制（或软链）到本目录：

```bash
cp -r ../../fonts ./fonts
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm install
CHROMIUM_PATH=/usr/local/bin/chromium npm run render
npm run sfx && npm run metrics
TITLE="教具已毕业" npm run encode
```

定格真静音窗口在"教具已毕业"章砸中后（约 25.3–26.1s）。无生成式模型、无外部素材。
