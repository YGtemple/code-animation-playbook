# 实例十四《人体开机自检报告》——复古黑白默片/老电影风（带 TTS 中文旁白）

> 30.000s / 1920×1080 / 30fps / 900 帧；H.264 High + yuv420p，AAC 48kHz 立体声，+faststart。
> 引擎与喜剧结构不变，换成 1920s 黑白默片（胶片颗粒/划痕/暗角/抖动 + 插卡标题）；含 TTS 中文人声旁白。

## 剧情

假期最后一晚，小职员对着「上班人格」做开机自检，五关 slapstick 层层加码；五灯全亮刚坐下，屏幕显示「距下班还有 9 小时 59 分」，整个人连椅后仰翻倒：

| 片头 | 纯黑片头卡 | 【卡】第14号·人体开机自检报告 |
| 抬头 | 趴桌猛抬头、头发炸、领带歪 | 【卡】长假最后一晚·他要开机了 |
| R1 眼皮 | 眼皮像生锈百叶窗掰不开，用火柴棍撑起来 | 自检 1/5 |

拼死开机成功，却发现「上班这件事，才刚刚开始」。
彩蛋：加载水印（片6《前额叶没坏，是累了》）、动力表小龙虾贴纸（片4《养龙虾》）、背后抖的手（背手负鼠）。

## 皮肤要点

- 灰阶 Rec.601 `Y=0.299R+0.587G+0.114B`；黑位抬到 Y≈12、白位滚到 Y≈232；
  S 曲线（中反差 ×1.18 + 轻微三次项，clip 12–232）；目标 mean Y≈100–115、std≈58–70；暖相纸 tint 默认关。
- 胶片：每帧时间不相关高斯颗粒 σ_g=7/255（逐帧全新、不复用）；粗霉斑 1–3 椭圆、脏点 3–8 个；
  竖划痕 2–5 条（约 40% 连续 3–8 帧）；每 4–6s 水平刮痕；每 6–9s 放映跳格 1–2 帧（全片 ≤4–5 处）；
  径向暗角四角压到 55%；gate weave 全局平移 Δx±2.2/Δy±1.0；flicker 整帧亮度系数 σ≈0.045。
- 插卡（风格本体，**不算烧字幕**）：黑底 `#0a0a0a`、米白 `#ece5d3`、硬切、每张停 1.6–2.2s、全片 ≤5 张；
  中文衬线 72–88px、字距 +10、行高 1.6、≤2 行居中；片头/片尾两张可双线框。
- 音乐：拉格泰姆老钢琴，108 BPM(2/4)、16–25s 升 120；左手 stride、右手切分反拍；
  进行 C–A7–D7–G7（I–vi–II–V）；走音旧立式（泛音+快衰减+微失谐）；28.5s 下行 glissando+琴盖砰急停。
  音效：放映机咔哒床声 −28dB、slapstick=boing+钢琴柱式重击、追魂=上行音阶+风带通、结尾唱片刮擦+静音0.3s、打卡机/钟表/纸抽 foley。
- **省盘架构**：playwright 只渲干净、高压缩的内容帧；`filmify.py` 在管道里施加灰度/颗粒/暗角/抖动并**直接 pipe 给 ffmpeg**，
  不落颗粒帧（颗粒 PNG 极大），同时在流上累计黑白指标。

## 旁白文案与音色（TTS，唯一生成式环节）

音色：**中年男、老派电影院讲解员/说书先生**，语速稳、咬字清晰，见怪不怪的无奈调侃、温润低沉，有 1920s 电台距离感，不演：

| 句 | 时间 | 文案 |
|---|---|---|
| V1 | 0.8s | 各位观众，今晚的主角，是一个正准备去上班的人。 |
| V2 | 6.8s | 开机自检第一项，眼皮。它已经三天，没醒过来了。 |
| V3 | 13.8s | 第四项，灵魂。假期那天，它被留在了海边。 |
| V4 | 21.4s | 终于，全部点亮。他以为，这就是胜利了。 |

## metrics 重定义（黑白口径，颜色类指标全废）

颗粒与抖动全程存在，直接帧差会被颗粒灌水、滤太净又会把卡死误判成静场。解法：**先配准 → 扣颗粒本底 → 3σ 分桶**。

1. 相位相关/质心估计相邻帧全局平移并配准，去 gate weave；
2. `D=|f_t−f'_{t−1}|`，扣颗粒本底 `μ_g=σ_g·√(2/π)≈5.6`，`net_motion=D.mean()−μ_g`（健康静场 ≈0，**不算运动也不算死帧**）；
3. 真运动阈值 `T=3·σ_g·√2≈30/255`，`motion_pixel_ratio=(D>T).mean()`；纯颗粒仅 ~0.3% 孤立散点，3×3 腐蚀后只算 >50px² 运动块；
4. 死帧：角部 128×128 平坦区实测 std 应 ≈σ_g±1.5，std<1 或帧字节完全相同 = 渲染 bug 死帧（静场 net≈0 正常）。

目标区间：mean 100–115、std 58–70、P5≈12–22/P95≈218–232、高光溢出(Y>238)<1%、平坦区颗粒 5.5–8.5、
净运动静场 0–3/动作 8–25、flicker 时序 std 3–6（1s 漂移 <15）、死帧数=0。
实测（pooled）：mean 125.8 / std 71.5 / P5 9.1 / P95 210、颗粒 6.25、净运动中位 2.0/p90 10.9、flicker 5.78、死帧 0、溢出 0.06%。

## 运行（Windows / PowerShell；其他系统同理）

> Playfair Display（拉丁/数字，OFL）已随示例（`fonts/`）。中文插卡用 Windows 已安装衬线 **SimSun（宋体）**、
> 无需 @font-face；跨平台可改用 OFL 的 Noto Serif SC 900（见下，体积大）。

```powershell
Copy-Item -Recurse -Force ..\..\node_modules .
# （可选，跨平台中文衬线）下载思源宋到 fonts/ 并把 render.js 的 'SimSun' 改为该 family
# curl.exe -L -o fonts/NotoSerifSC.ttf "https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/notoserifsc/NotoSerifSC%5Bwght%5D.ttf"

# 1) 逐帧干净内容帧（render_frames.js 已配本机 Chrome 路径）
node render_frames.js
# 2) 纯代码配乐/音效床（产出 bed.wav）
python sfx.py
# 3) TTS 旁白：用 text_to_audio_plus 逐句生成，裁剪静音后存为 voice/v1.wav … v5.wav
# 4) 旁白对位 + ducking 混音（产出 mix_voice.wav / mix_novoice.wav）
python mix_voice.py
# 5) 黑白胶片化（pipe→ffmpeg 出无声视频）+ 编码两版 MP4
python filmify.py
powershell -File encode.ps1
```

无生成式模型（TTS 旁白为明确例外）、无外部素材。
