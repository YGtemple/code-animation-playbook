# 换风格指南（Restyling Guide）

你后期要做不同视觉风格 / 题材，核心就一句话：

> **引擎不动，只换皮肤；内容重排，管线复用。**

- **引擎（保持不变）**：`timeline.js` 的时间驱动方式、`render.js` 的"建一次 + 纯函数 `render(t)`"、
  沸腾/滤镜机制、`render_frames.js` 的断点续渲、`sfx.py` 的合成与总线、`metrics.py`、`encode.sh`。
- **皮肤（每支片替换）**：色板、字体、图标/造型词汇、形状语言、纸纹/滤镜质感、音乐曲风与节奏型。
- **内容（按题材重排）**：`timeline.js` 里的事件 `T` 与音效线索；`render.js` 里的场景与文案。

---

## 一、皮肤的六个维度

### 1. 色板（Palette）

当前朋克拼贴的颜色（散落在 `render.js`，bg 在 world，卡片 / 墨色 / 红色到处用）：

| 用途 | 当前值 |
|---|---|
| 纸张底（world bg） | `#efe2c2`（米黄） |
| 纸面 / 卡片 | `#f5ebd2` |
| 近黑墨（线条/文字/投影） | `#1b1410` |
| 朱红（强调/按钮/印章） | `#d7261e` |
| 近黑底（黑场/横幅） | `#100c09` |

**换风格第一步（强烈建议）**：在 `render.js` 顶部把散落的颜色收敛成一个常量，之后换色只改这一处：

```js
const PALETTE = { paper:'#efe2c2', card:'#f5ebd2', ink:'#1b1410', accent:'#d7261e', dark:'#100c09' };
```

> 这一步是把"皮肤"从代码里剥离出来的起点。未来可进一步抽成 `styles/<风格名>.js`（见 ROADMAP）。

### 2. 字体（Fonts）

两处要一起改：

- `index.html` 的 `@font-face`（把字体文件放进 `fonts/`，改 `src` 和自定义家族名）；
- `render.js` 里所有 `font-family` 引用的 token（当前是 `ZCOOL / ZhiMang / MarkerF / AntonF`）。

字体气质要匹配风格：粗海报 / 毛笔 / 马克笔 / 窄粗体是朋克；极简用无衬线（如 Inter、Helvetica 风）；
赛博用等宽 / 科技体；水彩用圆润手写体。**务必用本地字体并在渲染前等 `document.fonts.ready`。**

### 3. 图标 / 造型词汇（Icons & Shape Vocabulary）

`render.js` 顶部的 `ICONS` 对象是一组 100×100 的简笔 SVG。换风格时改的是"怎么画"：

- **描边还是填充**：朋克是粗描边 + 局部填色；极简扁平是大色块填充、几乎无描边；
- **线宽与端点**：朋克 `stroke-width 8–11`、圆头；极简细线 / 直角；
- **圆角 vs 直角 vs 撕边**：决定整体性格；
- **造型复杂度**：细节多少、是否几何化 / 像素化。

题材换了，图标集合也要换（如交通图标 → 厨房 / 太空 / 办公图标），但"symbol + `<use>`"的组织方式不变。

### 4. 投影与质感（Shadow & Texture）

| 质感零件 | 朋克拼贴 | 换风格时 |
|---|---|---|
| 投影 | 实心偏移**硬投影** | 极简：去掉或极淡；赛博：霓虹外发光（feGaussianBlur+加色）；水彩：无硬边、用晕染 |
| 纸纹 | 高频颗粒 + 米纸 | 水彩：水彩纸纹 + 颜料晕；赛博：扫描线 / 噪点 / 故障；极简：几乎无纹 |
| 撕纸 / 胶带 | 有 | 极简 / 赛博去掉；换成对应风格的装裱元素 |

### 5. 沸腾 / 线条抖动（Boil）

- defs 里 `boil1/2/3` 用 `feTurbulence + feDisplacementMap`；当前 `baseFrequency 0.012 0.018`、`scale 10/11/13`，seed 每帧换。
- **手绘类风格（朋克 / 水彩）**：保留沸腾，水彩可降低 scale、换更柔的频率。
- **干净类风格（极简 / 瑞士网格 / 赛博矢量）**：把 boil 的 scale 调到 0（或不挂滤镜），线条保持锐利；
  此时为了不触发"死帧"，改用**其它逐帧运动**（元素位移、渐变、光效、扫描线）来保证画面在动。

### 6. 音乐曲风与节奏型（Music）

在 `sfx.py` 的 `build_music()` 里：当前 120BPM，按段落切了 `big / punk / double / tension / jazz / riser / end`
等风格段，乐器是 kick / snare / bass / 吉他刷弦等。换风格时：

- 换 **BPM** 与鼓组（赛博可用电子鼓 + 合成 bass；水彩用轻柔拨弦 / 钢琴；像素用 8-bit 方波 chiptune）；
- 换段落的节奏型与配器，但"画面事件对齐音乐重拍 / 落点"的原则不变；
- 音效音色也要跟着换（如像素风把 click/slam 换成方波 blip）。

## 二、风格对照表（起点建议，非教条）

> 同一维度在不同风格下的推荐值。数值是**起点**，先跑通再按画面微调。

| 维度 | 朋克拼贴（现状） | 极简扁平 | 赛博霓虹（暗底） | 水彩手绘 | 复古像素 / 8-bit |
|---|---|---|---|---|---|
| 底色 paper | `#efe2c2` 米黄 | 白 / 浅灰 `#f5f5f5` | 近黑深蓝 `#070a12` | 暖白水彩纸 `#f7f3ea` | 深灰 / 深青 `#1a1c2c` |
| 主墨 ink | `#1b1410` 近黑 | 炭灰 `#1f2937` | 青/品霓虹 `#3df5ff` `#ff3df0` | 柔灰褐 `#4a4239` | 受限调色板（4–16 色） |
| 强调 accent | `#d7261e` 朱红 | 单一高饱和点缀 | 霓虹品红 / 电光青 | 淡群青 / 赭石 | 亮黄 / 亮青 |
| 形状语言 | 撕边、粗黑线 | 大色块、直角/大圆角 | 锐利几何 + 发光描边 | 不规则柔边、晕染 | 硬边方块、无抗锯齿感 |
| 描边 | 粗 8–11、圆头 | 无 / 极细 | 中等 + 外发光 | 中等、毛糙 | 无描边（像素堆叠） |
| 投影 | 硬偏移实心 | 无 / 极淡 | 霓虹辉光 | 晕染无硬边 | 无 / 1px 硬阴影 |
| 质感 | 纸纹 + 撕纸 + 胶带 | 几乎无 | 扫描线 + 故障 + 噪点 | 水彩纸纹 + 水痕 | 像素颗粒 / 无 |
| 沸腾 boil | 强（scale 10–13） | 关闭 | 关闭（用故障/光效代替） | 弱（scale 3–6） | 关闭（逐帧步进动画） |
| 字体 | 粗海报 / 毛笔 / 马克笔 | 干净无衬线 | 等宽 / 科技显示体 | 圆润手写体 | 像素字体（8×8 点阵） |
| 音乐 | 120BPM 朋克摇滚 | 少而精 / 轻电子 | 中高速电子 / synthwave | 慢速原声 / 爵士 | 方波 chiptune |
| 运动补偿 | 沸腾 + 五件套 | 克制的位移/形变 | 光效 / 扫描 / 故障闪烁 | 弱沸腾 + 漂移动 | 逐帧 / 步进（天然无死帧） |

> 提示：暗底风格（赛博）要重写 `metrics.py` 的"黑+红面积"指标——暗底天然大面积黑，
> 原阈值会失真。换风格时**自检指标也要按新风格重新定义**（见 qa-checklist）。

## 三、题材 / 内容怎么换（`timeline.js` + `render.js`）

皮肤决定"长什么样"，题材决定"讲什么事"：

1. **重写事件表 `T`**：保留"fps / duration"和你需要的结构，替换成新故事的事件时间。
   重复动作仍用"起点 + 步长 + 次数"。
2. **重排音效线索**：在同一文件按新事件生成 `SFX_CUES`，注意 whoosh/riser 的"命中时刻"语义。
3. **替换场景与文案**：在 `render.js` 增删场景 `<g>`、改文字、换 `ICONS` 集合。
4. **保留五件套与喜剧手法**：backOut 入场、硬投影/对应质感、闪白/推镜、集中线、同帧音效；
   加速滴答、定格静音、跳切、递进、反差结尾这些手法与题材无关，可直接借用。

## 四、换风格标准动作（照这个顺序，最省事）

1. 从主仓库开新分支（或复制一份），起个风格 / 题材名；
2. 把 `render.js` 颜色收敛为顶部 `PALETTE`，按目标风格填新色板；
3. 换 `fonts/` 与 `index.html` 的 `@font-face`，替换字体 token；
4. 改 `ICONS` 的画法与集合、形状语言、投影 / 质感；
5. 调沸腾滤镜（手绘保留、干净风格关闭并用别的运动补偿）；
6. 改 `sfx.py` 的 BPM / 配器 / 段落曲风与音效音色；
7. 重写 `timeline.js` 的内容与节奏；
8. 按新风格调整 `metrics.py` 阈值；
9. `npm run all` → ffprobe + 抽帧目检 → 交付；
10. 把新踩到的坑写回 `docs/pitfalls.md`，把验证有效的皮肤参数沉淀下来。
